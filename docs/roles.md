# Team Roles & Responsibilities

Fill in team member names against the roles below. Roles can overlap for small teams.

| Role                | Responsibility                                              | Assigned To |
|---------------------|---------------------------------------------------------------|-------------|
| Project Lead        | Coordination, supervisor communication, sprint tracking       |             |
| Backend Developer   | API, database, auth, business logic                           |             |
| Frontend Developer (Mobile) | React Native app screens and state management         |             |
| Frontend Developer (Admin)  | React.js admin panel                                   |             |
| QA / Testing        | Manual testing, bug tracking, UAT coordination                 |             |
| DevOps / Deployment | Environment setup, hosting, CI basics                          |             |

## Notes
- For a small team, one person may hold more than one role.
- Update this table at the start of each sprint if responsibilities shift.
